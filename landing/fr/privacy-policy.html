Politique de confidentialité

Kadence — Dernière mise à jour : juin 2026

Ce que fait Kadence

Kadence est une application mobile pour planifier et suivre vos activités sportives hebdomadaires. Elle stocke vos séances d'entraînement localement sur votre appareil et les synchronise éventuellement dans le cloud lorsque vous vous connectez.

Données que nous collectons

Kadence collecte le minimum de données nécessaire à son fonctionnement :

  • Informations du compte — Si vous choisissez de vous connecter avec Google ou Apple, nous recevons votre nom, votre adresse e-mail et votre photo de profil du fournisseur. Ces informations servent à identifier votre compte et à afficher votre nom dans l'application.
  • Données d'activité — Les séances d'entraînement que vous créez (nom, type, date, heure, durée, notes et statut). Ces données sont stockées localement sur votre appareil et, si vous êtes connecté, synchronisées avec notre base de données cloud pour que vous puissiez y accéder depuis plusieurs appareils.
  • Données de calendrier — Si vous activez la synchronisation du calendrier, Kadence crée, met à jour et supprime les événements de calendrier correspondant à vos séances planifiées. Kadence ne lit ni n'accède à aucun autre événement de votre calendrier.
  • Données Strava — Si vous connectez votre compte Strava, Kadence lit votre historique d'activités pour associer les entraînements terminés à vos séances planifiées. Nous n'accédons qu'aux données d'activité nécessaires à cette fonctionnalité et ne stockons pas vos identifiants Strava — l'authentification passe par le flux OAuth2 de Strava.

Données que nous ne collectons pas

  • Nous ne collectons pas de données analytiques ou d'utilisation.
  • Nous n'utilisons pas de pixels de suivi, d'identifiants publicitaires ou de cookies.
  • Nous ne collectons pas de données de localisation.
  • Nous ne vendons, ne louons ni ne partageons vos données personnelles avec des tiers.

Où vos données sont stockées

Les données d'activité sont stockées localement sur votre appareil via SQLite. Si vous vous connectez, vos données sont également stockées dans une base de données cloud hébergée par Supabase (serveurs situés dans l'UE/aux États-Unis). Les données en transit sont chiffrées via HTTPS. L'accès à vos données cloud est protégé par Row Level Security — vous seul pouvez lire ou modifier vos propres activités.

Authentification

La connexion est gérée par Supabase Auth via Google et Apple comme fournisseurs d'identité. Kadence ne voit ni ne stocke jamais votre mot de passe. Les jetons d'authentification sont stockés de manière sécurisée sur votre appareil.

Conservation et suppression des données

Vos données sont conservées tant que vous utilisez l'application. Vous pouvez supprimer des activités individuelles à tout moment depuis l'application. Si vous vous déconnectez, vos données cloud restent stockées pour que vous puissiez y accéder ultérieurement. Pour supprimer définitivement toutes vos données et votre compte, contactez-nous à l'adresse ci-dessous.

Vie privée des enfants

Kadence ne s'adresse pas aux enfants de moins de 13 ans. Nous ne collectons pas sciemment d'informations personnelles auprès d'enfants.

Modifications de cette politique

Nous pouvons mettre à jour cette politique de temps en temps. La version la plus récente sera toujours disponible à cette URL. Les modifications importantes seront communiquées via l'application.
