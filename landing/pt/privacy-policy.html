Política de Privacidade

Kadence — Última atualização: junho de 2026

O que o Kadence faz

O Kadence é uma aplicação móvel para planear e acompanhar atividades desportivas semanais. Guarda as suas sessões de treino localmente no dispositivo e, opcionalmente, sincroniza-as na nuvem quando inicia sessão.

Dados que recolhemos

O Kadence recolhe apenas os dados mínimos necessários para funcionar:

  • Informação da conta — Se optar por iniciar sessão com Google ou Apple, recebemos o seu nome, endereço de e-mail e foto de perfil do fornecedor. Estes dados são usados para identificar a sua conta e mostrar o seu nome na aplicação.
  • Dados de atividade — As sessões de treino que cria (nome, tipo, data, hora, duração, notas e estado de conclusão). Estes dados são guardados localmente no seu dispositivo e, se tiver sessão iniciada, sincronizados com a nossa base de dados na nuvem para que possa aceder a partir de vários dispositivos.
  • Dados de calendário — Se ativar a sincronização com o calendário, o Kadence cria, atualiza e elimina eventos de calendário correspondentes às suas sessões planeadas. O Kadence não lê nem acede a quaisquer outros eventos do calendário.
  • Dados do Strava — Se ligar a sua conta Strava, o Kadence lê o seu histórico de atividades para associar treinos concluídos às sessões planeadas. Apenas acedemos aos dados de atividade necessários para esta funcionalidade e não guardamos as suas credenciais do Strava — a autenticação é feita através do fluxo OAuth2 do Strava.

Dados que não recolhemos

  • Não recolhemos dados analíticos ou de utilização.
  • Não usamos píxeis de rastreamento, identificadores de publicidade ou cookies.
  • Não recolhemos dados de localização.
  • Não vendemos, alugamos nem partilhamos os seus dados pessoais com terceiros.

Onde os seus dados são guardados

Os dados de atividade são guardados localmente no seu dispositivo usando SQLite. Se iniciar sessão, os seus dados são também guardados numa base de dados na nuvem alojada pelo Supabase (servidores na UE/EUA). Os dados em trânsito são encriptados via HTTPS. O acesso aos seus dados na nuvem é protegido por Row Level Security — apenas você pode ler ou modificar as suas próprias atividades.

Autenticação

O início de sessão é gerido pelo Supabase Auth usando Google e Apple como fornecedores de identidade. O Kadence nunca vê nem guarda a sua palavra-passe. Os tokens de autenticação são guardados de forma segura no seu dispositivo.

Retenção e eliminação de dados

Os seus dados são mantidos enquanto utilizar a aplicação. Pode eliminar atividades individuais a qualquer momento dentro da aplicação. Se terminar sessão, os seus dados na nuvem permanecem guardados para que possa aceder novamente mais tarde. Para eliminar permanentemente todos os seus dados e a sua conta, contacte-nos através do e-mail abaixo.

Privacidade de crianças

O Kadence não se destina a crianças com menos de 13 anos. Não recolhemos intencionalmente informação pessoal de crianças.

Alterações a esta política

Podemos atualizar esta política periodicamente. A versão mais recente estará sempre disponível neste URL. Alterações significativas serão comunicadas através da aplicação.
